# Customers Millénaire Appearance

Customers Millénaire Appearance is an optional NeoForge add-on for
[Customers](https://www.curseforge.com/minecraft/mc-mods/customers). It gives
Customers and Suppliers the local Millénaire village's culture, villager style,
clothing, and scale.

[Learn more about Millénaire](https://www.curseforge.com/minecraft/mc-mods/millenaire).

## Use the appearance

Install Customers, Architectury API, Millénaire, and this add-on. Place a
Customer Spawner or Supplier Spawner inside or near a Millénaire village, open
the spawner's appearance settings, and enable `Millénaire - Local Culture`.

The containing village is preferred. Otherwise, the nearest village can be
used when it is within the configured distance. Each spawned villager keeps
its selected culture and appearance after it leaves the village or the world is
reloaded.
