# Millénaire Appearance Configuration

Configure the add-on through NeoForge's mod configuration screen or
`config/customers_millenaire_appearance-common.toml`.

| Setting | Default | Effect |
| --- | ---: | --- |
| Maximum nearby-village distance | 128 | Maximum distance from the spawner to a fallback village center. |
| Include visitors | false | Allows visitor definitions. |
| Include leaders | false | Allows chief and leader definitions. |
| Include hostile and combat villagers | false | Allows hostile, raider, defensive, and combat definitions. |
| Include children | false | Allows child definitions. |

The optional groups are disabled by default so ordinary adult villagers remain
the normal Customer and Supplier appearance.
